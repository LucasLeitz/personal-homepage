Completed Media Library

A full-stack media tracking application for organizing and tracking completed books, movies, TV shows, and video games in one centralized library.

Designed as a personal productivity tool with a clean UI, backend API support, persistent database storage, and live web deployment.

Key Features

  • Track completed books, movies, shows, and games
  • Create, edit, and delete media entries
  • Organized media categories with reusable UI components
  • Responsive Angular frontend with clean user experience
  • REST API backend for data management
  • Live deployment with custom domain hosting

Tech Stack

Angular, TypeScript, Java, Spring Boot, MySQL, Docker, nginx
